# Peak

Minimal, open-source iOS workout and health tracking app.

- **Progressive overload** tracking for strength training
- **Weekly routine** management and rotation
- **HealthKit** integration (steps, water, sleep, HRV)
- **iCloud sync** via SwiftData + CloudKit
- **Import/Export** JSON, Excel, CSV

## Getting Started

1. Open `Peak.xcodeproj` in Xcode
2. Build and run on iOS 26.0+ simulator or device
3. See `docs/DEVELOPMENT.md` for setup details
