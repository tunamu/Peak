# 0010. English repository docs, English and Turkish UI

- **Status:** Accepted
- **Date:** 2026-09-29

## Context

Contributors can come from anywhere; the first users are Turkish speakers.

## Decision

Write all repository documentation in English. Localize the UI in English (base) and Turkish with a String Catalog.

## Consequences

- Every user-facing string needs a Turkish translation before merge (PR checklist).
