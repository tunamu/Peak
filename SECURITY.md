# Security Policy

## Supported versions

Peak has not been released yet. Security fixes go to the `main` branch; after release, only the latest App Store
version is supported.

## Reporting a vulnerability

Please do not open a public issue. Report privately through GitHub:
**Security** tab → **Report a vulnerability**
([direct link](https://github.com/tunamu/Peak/security/advisories/new)).

If that is not possible, email tunamuswork@gmail.com.

Please include what is affected, how to reproduce it and the possible impact. Peak is maintained by one person, so
reports are handled on a best-effort basis; you will get a reply once the report has been reviewed.

## Scope

Peak has no servers or accounts. Areas of interest are how the app handles imported files, Apple Health data and
iCloud sync.
